Maya Workflow Kit for Maya users, in Blender

The whole Maya workflow in Blender, in one install.

Other tools bring one piece over: a pivot tool, a keymap, a shelf. This rebuilds the set together — hotbox and marking menus, Channel Box and Attribute Editor, menu sets, shelves and option windows — on top of Blender's own tools. Installing it changes nothing until you choose Maya.

Install

Install Maya Workflow Kit

  1. Get the zip

    Download maya-workflow-kit-<version>.zip from GitHub Releases. The extensions.blender.org listing is not live yet.

  2. Install from disk

    In Blender 5.0 or later: Edit › Preferences › Get Extensions, open the drop-down at the top right and choose Install from Disk…, pick the zip. Or drag the zip onto the Blender window.

  3. Choose Maya

    Click Make Blender feel like Maya in the welcome dialog — or later, in the add-on preferences or with the Maya | Blender switch. Ctrl+Alt+Shift+M goes back.

Disabling or removing the extension unregisters everything it added — there is nothing else to undo. It writes only your shelves and the Maya project folders you create, and has no network access.

Recommended setup

Optional. The kit leaves your theme and Blender preferences to you; Maya users usually like:

  • A dark grey theme: Edit › Preferences › Get Extensions, filter by Themes and install one you like.
  • Navigation: Orbit Method Turntable, Orbit Around Selection off, Zoom to Mouse Position off, Auto Perspective on, Zoom Method Dolly with a horizontal axis.
  • Undo Steps set to 256 (Blender's maximum) under System.
  • Region Overlap off under Interface › Editors, so side panels sit beside the viewport.
  • Only Insert Available under Animation › Keyframes, for Maya-like auto key.

Where Blender's C++ draws the line

Everything here is Python on top of Blender. Some of Maya lives deeper than an extension can reach, so these are not imitated:

  • Blender is Z-up and has one pivot per object.
  • Dragging over a field with the middle mouse to scrub its value.
  • MEL. A Python Command Line with a small maya.cmds look-alike is there instead.
  • Side tabs and operating-system docking of panels.

Every Maya menu item Blender cannot do is still shown, greyed, with a one-line note saying why and what to use instead.

FAQ

Is this just a Maya keymap?

No. The keymap is one part. The kit adds Maya's layout, hotbox and marking menus, Channel Box and Attribute Editor, menu sets with Maya's menus, shelves, option windows with the same defaults as Maya, and Maya's scene concepts — Freeze, Delete History, Center Pivot, groups, centimetres, pCube1.

Will it change my Blender settings?

No. Maya mode adds keys, menus, panels and a layout; it never writes your theme, preferences or active keymap, and never saves preferences. The switch, disabling or removing the extension takes its additions away.

Can I follow Blender tutorials with it installed?

Yes: click Blender in the Maya | Blender switch (or Ctrl+Alt+Shift+M) for plain Blender with the same scene, and switch back afterwards.

Which Blender versions?

Supported: Blender 5.2 LTS. Other versions are not tested (it still installs on 5.0 and 5.1, but they may have problems). 0.6.2 is the last version for Blender 4.5 LTS.

Does it need Maya installed?

No. It contains no Autodesk code, icons or scripts and never talks to Maya; it rebuilds the behaviour in Blender.

Is it free?

Yes. The code is GPL-3.0-or-later; the kit's own images and data are CC0. Source and issues on GitHub.
